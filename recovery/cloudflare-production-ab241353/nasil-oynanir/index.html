Nasıl oynanır

Kontroller, konsol, oyun menüleri, sohbet komutları ve admin AMXX — hepsi tek sayfada.

Hemen Oyna Kontrollere git

Oyuna girmek

  1. Oyna sayfasına gir.
  2. Oyuncu adını yaz, sunucu listesinden bir sunucu seç veya Sunucular sayfasından katıl.
  3. İlk tıklamada ses ve kontroller aktif olur — tarayıcı izin isterse “İzin ver”.
  4. Bağlandıktan sonra M ile takım seç, spawn olunca B ile silah al.

Steam, kurulum veya launcher gerekmez. Güncel Chrome, Edge veya Firefox önerilir.

Harita süresi ve oy

Klasik sunucularda harita süresi genelde 30 dakikadır. Süre bitmeden yaklaşık 3 dakika kala otomatik harita oylaması açılır — sohbetteki numaralarla oyunu kullan.

Konsol nedir?

Konsol, oyuna komut yazdığın paneldir. Klasik CS’teki ~ yerine BrowserCS’te oyun ekranının üstündeki Konsol butonunu kullanırsın.

Nasıl açılır?

  1. Oyuna bağlandıktan sonra üst bardaki Konsol düğmesine tıkla.
  2. Komutu yazıp Enter ile gönder.
  3. Esc veya tekrar Konsol ile kapat.
  4. Yukarı / aşağı ok tuşlarıyla önceki komut geçmişine gidebilirsin.

Satın alma ipuçları

  • Round başında spawn bölgesindeyken B açılır.
  • Menüdeki numaralarla (1, 2, 3…) seçim yaparsın — klasik CS menü stili.
  • Para yetmezse seçenek gri / alınamaz; önceki round’dan biriken para kullanılır.

Admin komutları bir sonraki sekmede.

Admin / AMXX nasıl kullanılır?

Kiralık sunucu veya yetki verilen hesaplarda AMX Mod X menüleri ve komutları açıktır. Menüler RCON ile uzaktan açılmaz — oyuna bağlanıp kendi konsolundan çalıştırman gerekir.

1) Şifreyi kaydet

Sunucu sahibinin verdiği admin şifresini konsola bir kez yaz:

setinfo _pw "sifren"

Sonra yeniden bağlan veya retry at. Yetki yüklendiyse sohbette / konsolda admin olduğunu görürsün.

2) Ana menü

amxmodmenu

Ekranda numaralı AMXX menüsü açılır. Alt menülere sayı ile girersin.

3) Sık kullanılan menü komutları

KomutMenü

4) Panelden yönetim

Kiralık sunucu paneli (Sunucu Kirala / hesabın sunucu ayarları) üzerinden de harita değiştirme, kick, bot ekleme-çıkarma gibi işlemler yapılabilir. AMXX menü komutları ise yalnızca oyundayken client konsolunda çalışır.
